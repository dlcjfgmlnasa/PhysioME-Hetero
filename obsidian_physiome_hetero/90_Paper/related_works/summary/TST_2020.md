# TST — Transformer for Multivariate Time Series Representation Learning

## TL;DR
일반 multivariate time-series 에 Transformer 를 적용한 첫 unsupervised pretraining framework. **Masked input reconstruction** 을 사전학습 objective 로 사용해 fully-supervised SOTA 를 능가하는 transfer 성능 달성.

## Domain & Task
- 일반 multivariate time-series (UEA / UCR archive 의 30+ benchmark)
- Regression · Classification · Forecasting · Imputation downstream

## Method
- **Encoder-only Transformer** (BERT-style)
- **Pretraining objective** : Masked input reconstruction
  - 입력 시계열의 랜덤 시점 (~15%) 을 마스크 토큰으로 대체
  - 원본 값을 MSE 로 복원
  - 시간축 마스킹 (geometric distribution 으로 contiguous block 단위)
- Position encoding : learnable absolute
- Normalization : input standardization (per-feature)

## Datasets
- 11 multivariate UEA benchmark (분류)
- 6 monash forecasting archive
- Sample 수 ~수만 ~ 수십만

## Key Results
- Unsupervised pretraining → Fine-tuning 이 fully-supervised 보다 평균 +5% accuracy
- Few-shot regime (≤ 1k labels) 에서 효과 가장 큼
- 데이터셋 별 아키텍처 튜닝 없이 일반 transformer 로 SOTA

## Relation to 본 연구
- **Masked Patch Modeling** 의 original time-series transformer 선조 — 본 연구의 사전학습 objective $\mathcal{L}_{\mathrm{recon}}$ 의 직접적 baseline
- Related Work 에서 **"masked time-series pretraining"** 카테고리 대표 인용
- 단점 : 일반 시계열용 — 생체신호의 multi-modal heterogeneity 나 channel-level identity 처리 없음

## Limitations / 차이
- Patch-level 이 아닌 token-level (1 시점 = 1 token) — 본 연구는 patch token 사용
- Single-variate 또는 stacked-channel 처리 — modality 별 type embedding 없음
- Random length sampling, FFD packing 같은 효율화 미도입
