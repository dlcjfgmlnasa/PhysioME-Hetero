# 3KG — Contrastive Learning of 12-Lead ECG with Physiologically-Inspired Augmentations

## TL;DR
일반 contrastive augmentation (random crop, masking) 대신 **VCG (Vectorcardiogram) 공간의 3D 회전·반전** 같은 생리학적 변환을 contrastive learning 의 augmentation 으로 사용. PhysioNet 2020 challenge 23-class 진단에서 1% labeled data 만으로 best SSL baseline 대비 mean AUC +9.1%.

## Domain & Task
- 12-lead ECG → VCG 공간 변환
- 다중 라벨 부정맥·전도 이상 분류 (PhysioNet 2020, 23 클래스)
- Linear probe / fine-tuning evaluation

## Method
- ECG → VCG (3D 심전 벡터) 변환 후, VCG 공간에서 **3D rotation, sign-flip 등 physiological 변환** 적용
- 변환된 VCG → 다시 12-lead ECG 로 역변환
- 두 개의 random 변환 결과를 SimCLR-style positive pair 로 사용
- Encoder : 1D-CNN
- Loss : NT-Xent
- Spatial + temporal augmentation 결합이 가장 강력

## Datasets
- PhysioNet 2020 challenge data (다기관, 다양한 부정맥)

## Key Results
- 1% labeled data : best SSL baseline 대비 mean AUC +9.1%
- 특히 **conduction abnormality, rhythm 이상** 진단에서 큰 개선
- 도메인 특화 augmentation 의 효용성 입증

## Relation to 본 연구
- **Physiologically-inspired contrastive augmentation** 의 대표 사례 — Related Work 의 인용 후보
- 본 연구의 Cross-Modal Contrastive Learning 도 *"같은 환자의 다른 modality"* 라는 생리학적 prior 을 positive 로 사용 → 3KG 의 *"VCG 공간 회전"* prior 와 같은 철학
- 단, 3KG 는 단일 modality 내 augmentation, 본 연구는 modality 간 alignment

## Limitations / 차이
- ECG-only, VCG 변환 의존 → 다른 modality (ABP, PPG 등) 일반화 어려움
- 1D-CNN encoder, single-task 평가
- Foundation model scale 사전학습 아님
