# BIOT — Biosignal Transformer for Cross-data Learning (NeurIPS 2023)

## TL;DR
EEG, ECG, human activity sensor 등 **다양한 biosignal 을 단일 Transformer 로 통합**. Channel 수·길이·결측 이질성을 *"sentence"* 형식 tokenization 으로 해결. Cross-dataset learning 의 대표 framework.

## Domain & Task
- EEG, ECG, HAR (인체 활동) — 다양한 biosignal 통합
- Cross-dataset 학습 (서로 다른 channel 구성·sampling rate·길이)

## Method
- **Tokenization 통일** : 모든 biosignal 을 *"channel × time patch token"* 의 sentence 로 변환
- Mismatched channel·variable length·missing values 모두 처리
- Transformer encoder
- Pretraining 가능 (단일 task 학습 + cross-data transfer 모두 가능)

## Datasets
- 다양한 EEG, ECG, HAR public dataset
- Cross-dataset 학습 평가

## Key Results
- 같은 도메인 내 task 에서 robust baseline 능가
- 다른 데이터셋 간 transfer 능력 입증
- GitHub : https://github.com/ycq091044/BIOT

## Relation to 본 연구 (직접 baseline)
- **Multi-biosignal unified Transformer** 의 대표 — 본 연구의 architecture 이념 ("단일 인코더로 6 종 신호 통합") 의 직접 선조
- Channel × time patch tokenization = 본 연구의 patch + Dual Embedding 의 prequel
- Mismatched channel 처리 = 본 연구의 Sequence Packing + Dual Embedding 과 같은 motivation
- 단, BIOT 는 cross-dataset 일반화 focus, 본 연구는 cardiovascular 임상 task focus

## Limitations / 차이
- ECG·EEG·HAR 의 일반 biosignal — cardiovascular invasive (ABP, CVP, PAP, ICP) 미지원
- Cross-modal coupling (모달리티 간 생리적 결합) 학습 메커니즘 부재
- LSCNorm 같은 loc/scale conditioning 없음
