# 06. Experiments 설계

## 6.1 데이터셋

### Pretraining (SSL)
- **VitalDB** (메인) — SNU Vital Lab 공개, 수술 중 모니터링 ~6,388 case
- 모달리티: **ABP, ECG, PPG** 3종 (`SNUADC/ART`, `SNUADC/ECG_II`, `SNUADC/PLETH`)
- 100 Hz, 60초 윈도우

### Downstream evaluation
- **Primary**: VitalDB 수술 중 저혈압 (IOH) 예측
  - 라벨: 5/10/15분 후 horizon 내 MAP < 65 mmHg ≥1분 지속 ([[../downstream/tasks/hypotension.py]])
  - Window×horizon sweep
- **Secondary 1**: Postoperative AKI prediction
  - 라벨: KDIGO Cr criteria from VitalDB clinical/lab CSV ([[../downstream/tasks/aki.py]])
  - 외부 CSV 의존
- **Secondary 2 (선택)**: Mortality prediction
  - MIMIC-III WDB cohort 기반 — external transfer 측면도 겸 ([[08. External transfer]])

### External transfer
- **MIMIC-III Waveform Matched Subset** — ICU, 미국 데이터, ~10,282 환자
- VitalDB pretraining → MIMIC-III 직접 transfer (zero-shot or linear probing)
- single-dataset 비판 무력화

## 6.2 전처리 파이프라인

`dataset/data_parser/_signal_filters.py::preprocess_channel` — Biosignal-Foundation-Model에서 가져온 신호별 robust pipeline:

1. **Range check** → 범위 외 → NaN
2. **Spike detection** (electrocautery, MAD 기반)
3. **Median filter** (ABP/PPG, kernel=5)
4. **Notch filter** (ECG/PPG, 60 Hz)
5. **Bandpass / Lowpass** (signal-specific cutoffs)
6. **Resample** to 100 Hz (필요 시 — MIMIC은 125Hz native)

신호별 설정 ([[../dataset/data_parser/_signal_filters.py]]의 `SIGNAL_CONFIGS`):
- ECG: bandpass 0.5–40 Hz, notch 60 Hz, range [-5, 5] mV, spike 10·MAD
- ABP: lowpass 0–15 Hz, range [20, 300] mmHg, median k=5, spike 6·MAD
- PPG: lowpass 0–8 Hz, range [0, 2000], median k=5, notch 60 Hz, spike 6·MAD

## 6.3 학습 setup

### Phase 1 — Unimodal pretraining
- 각 모달리티 (ABP/ECG/PPG)에 대해 NeuroNet 독립 학습
- 30 epochs, batch 256, AdamW, cosine lr scheduler
- ([[../config/vital_db/dp_neuronet.yaml]])

### Phase 2 — Multimodal PhysioME-Hetero
- Phase 1 ckpt → LoRA-wrapped backbone
- 50 epochs, effective batch 128
- Hetero bucket sampling, natural distribution
- ``restoration_only_on_complete=True`` (default)
- ([[../config/vital_db/physiome_hetero.yaml]])

### Phase 3 — Downstream finetuning / probing
- Linear probing: encoder frozen, classification head만 학습
- Full finetune: encoder + head end-to-end
- 두 가지 모두 보고 → reviewer는 어느 쪽이 fair인지 다양

## 6.4 평가 metric

### IOH (binary classification, class imbalance 큼)
- **AUROC** (관습 metric)
- **AUPRC** (imbalance에서 핵심)
- Threshold-bound: **Sensitivity, Specificity, PPV, NPV** at optimal/Youden threshold
- **Calibration plot** (predicted prob vs observed) — JBHI reviewer 가산점

### AKI / Mortality
- AUROC, AUPRC, F1 (binary)
- Stage prediction (multi-class) AKI: macro-F1

### Robustness 측정
- 모든 결손 시나리오 (8개 sub-pattern, single-modal부터 all-modal까지) 별 수치
- **결손 시나리오 평균** + **시나리오 표준편차** 둘 다 보고

## 6.5 비교 baseline

1. **PhysioME 원본** (synthetic-only, 우리 코드에서 재학습) — primary baseline
2. **Modality-specific dedicated 모델** (각 가용성 패턴별 별도 모델) — single-model 우월성 입증
3. **Naive late fusion** (각 모달 unimodal SSL → concat 후 classifier)
4. **Zero-fill imputation** (결손 모달을 0으로) + 원본 PhysioME

## 6.6 Surgery-type stratification

> [!warning] Confounding 위험
> VitalDB에서 modality availability는 surgery type과 correlate 가능 (e.g., 짧은 외래 시술은 ABP 없음). Bucket이 surgery-type confound를 유발할 수 있음.

대응:
- 같은 surgery type 내에서도 결손 robust한지 측정
- supplementary table: surgery-type × bucket × downstream metric 분해
- (선택) surgery type을 explicit covariate로 포함하는 분석

## 6.7 한계와 mitigation

| 한계 | mitigation |
|---|---|
| Single-pretraining-dataset (VitalDB) | MIMIC-III WDB transfer 1개 표 ([[08. External transfer]]) |
| Bucket-surgery confound | surgery-type stratified evaluation |
| Synth/real missing 분리는 완벽하지 않음 (real missing 중에도 artifact-induced도 있음) | discussion에서 언급 |
| AKI/mortality는 외부 CSV 필요 | reproducibility 위해 prepared script + 데이터 출처 명시 |
