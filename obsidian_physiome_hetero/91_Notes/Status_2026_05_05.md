## smoke 검증

세 smoke test 모두 CPU에서 통과:

```
[hetero]    7 buckets, presence {0,2}, miss=0 on hetero buckets, miss>0 on 111
[tfc]       4 losses fire, all 7 modules grad, 5.74→0.14 in 30 steps
[downstream] 7 modal subsets all forward, fc grads, backbone frozen
```

→ Loss 변경에 대한 불안감 해소 완료. 실데이터 학습 시 추가 sweep 필요한 것:

- TF-C `temperature` 0.01 → 0.05 / 0.1 sweep (default 너무 작을 가능성)
- L_TF 초기값이 다른 loss 대비 6× 큼 (4.26 vs 0.36~0.90) — 초반 dominance 가능성, recon이 안 떨어지면 weighting 도입
