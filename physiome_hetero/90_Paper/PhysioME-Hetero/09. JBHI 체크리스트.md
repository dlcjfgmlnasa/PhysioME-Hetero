# 09. IEEE JBHI 제출 체크리스트

## 페이지 / 형식

- [ ] IEEE Trans. 양식 (LaTeX 템플릿)
- [ ] 본문 ≤10 페이지 (overlength 비용 고려 시 13p까지)
- [ ] 그림은 sub-figure로 효율 사용 (4개 이내 권장)
- [ ] 표는 본문에 핵심만 (≤4), 나머지는 supplementary
- [ ] References ≥30개

## 필수 콘텐츠 (JBHI reviewer 평가축 기반)

### Methodology rigor
- [ ] 명확한 problem statement (introduction 첫 두 단락)
- [ ] formal 수식 (loss, presence embedding 식)
- [ ] 아키텍처 다이어그램 (figure 1)
- [ ] hyperparameter 표 (supplementary)
- [ ] random seed / reproducibility 명시

### Clinical relevance
- [ ] IOH의 임상적 정의 정확히 ([[06. Experiments 설계#6.4 평가 metric]])
- [ ] **Calibration plot** (predicted prob vs observed event rate) — figure 또는 supplementary
- [ ] Operating point에서의 Sens/Spec/PPV/NPV
- [ ] Failure case 정성 분석 (Task 12) — 1 figure로 wave 시각화

### Comparison rigor
- [ ] State-of-the-art baselines (≥3개)
- [ ] **PhysioME 원본 직접 재학습 결과** (published 수치 그대로 쓰지 않음)
- [ ] 통계적 유의성 (paired t-test, bootstrap CI 등)
- [ ] Matched compute 명시 (A1 ablation 핵심)

### Ablations
- [ ] A1: Synthetic vs Hetero (메인)
- [ ] A2: Real-missing vs Synth-missing test split (메인)
- [ ] A3: Restoration loss scope (supplementary OK)
- [ ] Single-knob: presence emb on/off (supplementary)

### External validity
- [ ] **MIMIC-III transfer** ([[08. External transfer]])
- [ ] 외부 데이터의 다른 분포에서도 동작함을 표 1 줄로 입증

### Reproducibility
- [ ] **GitHub 코드 공개** (paper acceptance 전후 결정)
- [ ] 환경 설정 (Python, PyTorch 버전) 명시
- [ ] 데이터 다운로드/전처리 스크립트 포함
- [ ] Pretrained checkpoint 공개 (Zenodo / HuggingFace)

## 작성 시 톤·스타일

- 1인칭 복수 (we) 사용
- 단정 표현 자제, hedge 언어 ("we observe ...", "this suggests ...")
- 원본 PhysioME에 대한 비판은 정중 ("the original PhysioME framework provides a strong starting point; here we extend it with the following insight ...")
- Bug fix 언급은 "we identify and resolve" 형태로 contributing improvement 톤

## 제출 직전 마지막 점검

- [ ] Abstract 첫 문장 = paper의 한 줄 메시지 (synthetic missing = OOD)

- [ ] Table 1 = 모든 결손 시나리오 평균 (위)
- [ ] Table 2 = A2 ablation (real vs synth missing)
- [ ] Discussion에서 limitations 솔직 언급
- [ ] Conclusion 마지막 문장 = clinical impact ("...applicable to real OR/ICU monitoring scenarios where modality drop is the norm, not the exception.")
