# 04. Method (한글) — 코드 기반 정리

> [!info]
> 본문 paste 전이지만, 코드(`models/physiome/model.py`)를 역공학하여 아키텍처와 손실은 정확히 정리. 본문 paste 후 검수 권장.

## 4.1 전체 파이프라인

PhysioME는 **두 단계** SSL pretraining + downstream finetuning으로 구성:

1. **Phase 1 — Unimodal SSL pretraining** (모달리티별 독립)
   - 각 모달리티 (ABP/ECG/PPG)에 대해 `NeuroNet` 단일 모델 학습
   - 손실: Masked Autoencoder (MAE) reconstruction + NTXent contrastive
   - 결과: 모달리티별 사전학습된 `NeuroNetEncoder`
2. **Phase 2 — Multimodal SSL pretraining** (PhysioME)
   - Phase 1 encoder들을 **LoRA-adapter로 wrap**하여 backbone으로 사용
   - 멀티모달 ViT encoder + 두 개의 decoder로 학습

## 4.2 Phase 1 — DP-NeuroNet

`models/dp_neuronet/model.py::NeuroNet`

- **FrameBackBone**: 1D ResNet으로 짧은 시간 윈도우(예: 4초) 임베딩
- **MaskedAutoEncoderViT**: 프레임 토큰 위 ViT 기반 MAE
- **Dual-Path**: 같은 입력에 두 가지 augmentation 적용 → 두 latent 사이 contrastive

수식 (재구성):

$$
\mathcal{L}_{\text{Phase1}} = \mathcal{L}_{\text{MAE}}(x, \hat{x}) + \alpha \cdot \mathcal{L}_{\text{NTXent}}(z_1, z_2)
$$

## 4.3 Phase 2 — PhysioME 멀티모달 모델

`models/physiome/model.py::PhysioME`

### 4.3.1 입력 처리

각 모달리티 $m$:
- LoRA-wrapped backbone으로 토큰 시퀀스 추출 → `encoder_out[m]` ∈ ℝ^(B × (1+L) × d_b)
- `backbone_embedded[m]` MLP로 dimension 일치
- 모달리티 토큰 + 2D sin-cos pos embedding 가산

### 4.3.2 멀티모달 인코더

모든 모달리티 토큰을 시간축으로 concat → ViT 블록 통과 → fusion 표현

$$
z_{\text{fusion}} = \text{ViT}_\text{multi}\bigl( \text{concat}_m [\text{Patch}(x_m) + e_m + p] \bigr)
$$

### 4.3.3 두 개의 decoder

- **Inter-modal masked decoder** (`forward_decoder`): 마스킹된 토큰을 fusion 표현에서 복원 → `inter_recon_loss`
- **Restoration decoder** (`forward_restoration_decoder`): 결손 모달리티 토큰을 복원 → `missing_recon_loss`

### 4.3.4 Cross-contrastive loss

Fusion 표현과 각 모달리티 unimodal 표현 사이 NTXent

$$
\mathcal{L}_{\text{contra}} = \frac{1}{|M|} \sum_{m \in M} \text{NTXent}\bigl( \mathrm{proj}_{\text{fusion}}(z_{\text{fusion}}),\ \mathrm{proj}_{m}(z_m) \bigr)
$$

### 4.3.5 전체 손실

$$
\mathcal{L}_{\text{Phase2}} = \mathcal{L}_{\text{inter-recon}} + \mathcal{L}_{\text{missing-recon}} + \mathcal{L}_{\text{contra}}
$$

## 4.4 추론 시 결손 처리

`PhysioME.inference_missing_modality(data)`:
1. 가용 모달리티만 인코더 통과
2. Restoration decoder가 결손 모달리티 토큰 생성
3. 복원된 토큰 + 실제 토큰 concat → 멀티모달 인코더 재통과
4. fusion 표현 출력

## 4.5 우리가 발견한 한계 (PhysioME-Hetero에서 정조준)

- **Synthetic missing 가정**: 학습 시에는 complete data만 사용, 결손은 인위적 drop으로 시뮬레이션
- **두 개 구현 버그** (자세히: [[../논문 PhysioME-Hetero/03. Method - Hetero-bucket#원본 PhysioME에서 발견된 버그]])
  - `forward_restoration_decoder` split_size 불일치
  - `forward_decoder`/`forward_restoration_decoder`의 ``.detach().contiguous()`` 위치 → recon loss가 decoder를 학습시키지 못함
