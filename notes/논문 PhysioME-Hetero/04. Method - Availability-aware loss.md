# 04. Method - Availability-aware loss decomposition

## 4.1 핵심 원칙

> [!quote]
> **각 학습 신호는 GT가 존재하는 곳에만 적용한다.**

이 한 줄이 loss 분해의 전부다. PhysioME 원본은 모든 batch에서 동일한 3개 손실을 모두 계산했지만, hetero 분포에서는 GT 유무가 sample별로 다르므로 분리해야 한다.

## 4.2 세 가지 손실의 적용 조건

| 손실 | 적용 조건 | 적용 위치 (mask) |
|---|---|---|
| `L_inter_recon` (masked recon) | 가용 모달리티가 있는 모든 batch | batch에 존재하는 모달의 마스킹된 토큰 |
| `L_cross_contra` (fusion ↔ unimodal) | 가용 모달리티 ≥1 | 각 가용 모달 unimodal 표현과 fusion 표현 사이 NTXent |
| `L_restore` (missing recon) | (default) complete bucket의 synth-drop 모달 / (ablation A3) 임의 batch의 synth-drop된 모달 | synth-drop된 위치만 (mask=1), naturally-absent는 mask=0 |

## 4.3 수식

Batch $\mathcal{B}$의 modality availability bitmap $b \in \{0,1\}^M$, synthetic drop bitmap $d \in \{0,1\}^M$ ($d_m \le b_m$).

### 4.3.1 Inter-modal masked reconstruction

$$
\mathcal{L}_{\text{inter}} = \frac{1}{|\mathcal{M}_\text{present}|} \sum_{m: b_m=1} \frac{\|\mathbf{m}_m \odot (\hat{x}_m - x_m)\|_2^2}{\|\mathbf{m}_m\|_1}
$$

$\mathbf{m}_m$ — random masking 마스크.

### 4.3.2 Cross-contrastive

$$
\mathcal{L}_{\text{contra}} = \frac{1}{|\mathcal{M}_\text{present}|} \sum_{m: b_m=1} \mathrm{NTXent}\bigl(\phi_\text{fus}(z_\text{fus}),\ \phi_m(z_m)\bigr)
$$

### 4.3.3 Restoration

$$
\mathcal{L}_{\text{restore}} =
\begin{cases}
\frac{1}{|\mathcal{M}_\text{drop}|} \sum_{m: d_m=1} \|\hat{x}_m - x_m\|_2^2 & \text{if } \mathcal{M}_\text{drop} \neq \emptyset \\
0 & \text{otherwise}
\end{cases}
$$

기본 모드 (``restoration_only_on_complete=True``): $\mathcal{M}_\text{drop} \neq \emptyset$가 되려면 $b = \mathbf{1}$ (complete bucket).
일반 모드 (ablation A3): $b_m = 1$인 모달 중에서 random하게 1개 이상 drop 가능.

### 4.3.4 전체

$$
\mathcal{L} = \mathcal{L}_{\text{inter}} + \mathcal{L}_{\text{restore}} + \mathcal{L}_{\text{contra}}
$$

## 4.4 왜 이 분해가 필요한가

기존 PhysioME 원본을 hetero data에 그대로 적용하면:
- ECG+PPG bucket batch: ABP가 존재 안 하는데도 forward에서 ABP 토큰을 가정 → 코드 crash 또는 0-vector로 처리되어 noise loss
- 자연 결손인 ABP에 대해 restoration loss를 계산하려 해도 GT 없음 → 학습 신호 부정합

분해된 loss는:
- 가용 정보로 표현 학습 (`inter`, `contra`)
- 합성 결손에서만 복원 학습 (`restore`)
- 두 신호를 깨끗이 분리하므로 모델은 각 task가 명확한 supervision을 받음

## 4.5 구현

`models/physiome/model.py::PhysioME.forward(...)` 시그니처:

```python
def forward(
    self,
    data: Dict[str, Tensor],
    presence_state: Optional[Tensor] = None,
    mask_ratio: float = 0.8,
    simulate_drop: bool = True,
    restoration_only_on_complete: bool = True,  # ← A3 ablation toggle
) -> Tuple[Tensor, Tensor, Tensor, Tensor]:
    ...
```

`presence_state`: BatchSampler에서 자동 생성 (real-present=0, naturally-absent=2).
``_synthetic_drop_restoration``이 GT 유무로 mask=0/1 분기.
