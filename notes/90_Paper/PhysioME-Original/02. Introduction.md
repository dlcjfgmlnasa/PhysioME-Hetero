## 일반적인 Introduction 구조 (PhysioME에 적용)

### 1. 문제 제기 (motivation)

- 임상 환경에서 생리신호 멀티모달 모니터링이 표준
- 그러나 hardware 한계, motion artifact, 환자 상태 변화 등으로 모달리티 결손이 빈번
- 결손 시 기존 모델 성능 급락 — clinical deployment 가로막는 핵심 장애물

### 2. 기존 접근의 한계

- 모달리티 결손에 대한 단순 imputation (zero-fill, mean-fill)은 표현력 부족
- modality-specific 모델 ensemble은 비용이 큼
- 멀티모달 SSL은 발전했으나 결손 시나리오 명시적 학습은 부재

### 3. 제안 방법 (PhysioME)

- 멀티모달 SSL + restoration decoder 조합으로 결손 입력 직접 처리
- Masked prediction + contrastive 학습으로 라벨 부족 문제 동시 해결
