# 00. 핵심 메시지 — paper의 한 줄

> [!quote] One-liner
> **"Multimodal SSL with synthetic missing-modality drop is an out-of-distribution generalization problem. We close the gap by training on the real heterogeneous availability distribution itself."**

## 30초 elevator pitch (한글)

기존 멀티모달 자기지도 학습은 "모든 모달리티가 갖춰진 데이터에서 학습한 뒤 추론 시 일부를 인위적으로 가려보는" 방식으로 결손에 대응한다. 그러나 이는 본질적으로 **OOD 일반화 문제** — 학습 분포(complete)와 배포 분포(real missing) 사이의 covariate shift다. **PhysioME-Hetero**는 학습 분포를 처음부터 실제 가용성 분포에 맞춘다. 모달리티 가용성 패턴별 bucket 샘플링, GT 유무에 따른 **availability-aware loss 분해**, 그리고 **3-state presence embedding** (real-present / synthetically-dropped / naturally-absent) 세 요소로 구성된다. VitalDB 수술실 데이터의 ABP/ECG/PPG 멀티모달에 적용하여 **수술 중 저혈압(IOH) 예측을 메인 task**로 삼는다.

## Contribution 4 bullet (paper 초안용)

1. **Distribution-shift 프레이밍** — synthetic vs. real missing modality를 covariate shift로 정형화. 단순 OOD test가 아니라 학습 분포 자체를 바꿔야 함을 동기로 제시
2. **Hetero-bucket SSL training** — 가용성 패턴별 bucket 샘플링으로 *natural*하게 결손된 케이스를 학습 신호에 포함. 데이터 활용도 100%
3. **Availability-aware loss 분해** — `inter_recon` / `cross_contra`는 가용 모달에만, `restoration`은 GT 보유한 (complete bucket의 synth drop 또는 임의 batch의 synth-drop된 모달) 위치에만 적용
4. **3-state presence embedding** — real-present / synth-dropped / naturally-absent를 모델이 명시적으로 구분 → 추론 시 결손 종류에 적응

## 추가 contribution (보조)

- **2개의 PhysioME 원본 코드 버그 수정** (split_size 불일치, decoder `.detach()` 위치) — re-run baseline으로 공정 비교
- **MIMIC-III WDB external transfer** — single-dataset 비판 무력화
- **VitalDB 위 다중 downstream** — IOH (메인) + AKI/mortality 보조

- VitalDB는 SNU Vital Lab 자체 공개 데이터 → reviewer가 데이터 신뢰성에 의심 못함
