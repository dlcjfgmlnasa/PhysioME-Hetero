# 11. Phase-1 SSL — Time-Frequency Consistency (TF-C)

## 11.1 왜 SimCLR이 아닌가

원본 NeuroNet은 두 개의 SimCLR (NT-Xent) loss를 사용했다:
- ``contrastive_loss1``: random masking으로 만든 두 view 간 contrastive
- ``contrastive_loss2``: 두 augmented input 간 contrastive

문제: **biosignal에서 false-negative 빈발**.
- 같은 환자(subject_id)의 다른 60초 window는 base hemodynamic state가 거의 같음 — 사실상 positive에 가까움. 그러나 NT-Xent는 강제로 negative로 밀어냄.
- 같은 surgery type / 같은 시점대 segment도 마찬가지.
- 결과: cardiac signal의 fine-grained pattern을 학습하지 못하고 trivial한 instance discrimination만 됨.

또한 sleep-EEG-style augmentation (segment crop / 5-permutation)은 **cardiac periodic 신호의 임상 정보(HR · HRV · respiratory modulation)를 직접 망가뜨림**.

## 11.2 TF-C 핵심 아이디어 (Zhang et al., NeurIPS 2022)

같은 신호의 **시간 도메인 view**와 **주파수 도메인 view**를 같은 latent space로 매핑하도록 강제. False-negative 문제를 cross-domain alignment라는 **다른 supervisory signal**로 우회한다.

세 가지 loss:

$$
\mathcal{L}_{\text{TF-C}} = \mathcal{L}_T + \mathcal{L}_F + \mathcal{L}_{TF}
$$

| Term | 의미 | NeuroNet 구현 |
|---|---|---|
| $\mathcal{L}_T$ | 같은 신호 두 time view 간 contrastive | random mask 두 번 → 두 cls_t → ``projector_time`` → NT-Xent |
| $\mathcal{L}_F$ | 같은 신호 두 freq view 간 contrastive | random mask 두 번 → 두 cls_f → ``projector_freq`` → NT-Xent |
| $\mathcal{L}_{TF}$ | **time CLS와 freq CLS는 같은 instance니 positive** | cls_t, cls_f → ``projector_tfc`` → NT-Xent |

여기에 두 도메인 모두에 대해 MAE reconstruction loss를 계속 적용:
$$
\mathcal{L}_{\text{Phase-1}} = \mathcal{L}_{\text{recon-T}} + \mathcal{L}_{\text{recon-F}} + \mathcal{L}_T + \mathcal{L}_F + \mathcal{L}_{TF}
$$

## 11.3 PhysioME-Hetero 맥락에서의 적합성

ABP / ECG / PPG는 모두 cardiac periodic 신호. **임상적으로 중요한 정보(HR · HRV · respiratory modulation · pulse pressure variation)는 frequency domain에서 훨씬 명시적**. Time-domain encoder만으로는 학습하기 어려운 spectral feature를 freq view가 explicit supervisory signal로 제공한다.

JBHI reviewer 관점:
> Q. *왜 cardiac signal에 이 SSL을 썼나?*
> A. *Cardiac periodicity와 spectral feature(HR, RR ratio)는 frequency domain에서 더 직접 노출되므로, time/freq cross-domain consistency가 single-domain SimCLR보다 임상 의미를 더 잘 보존한다.*

## 11.4 구현 (코드 참조)

- ``models/dp_neuronet/model.py::NeuroNet``
  - ``frame_backbone`` (time) + ``frame_backbone_freq`` (FFT magnitude, zero-padded to W로 같은 backbone arch 재사용)
  - ``autoencoder``는 **공유** (patch_embed + transformer encoder + cls_token + decoder) — 이 shared encoder가 Phase-2로 이전되는 universal representation
  - 3개 projector: ``projector_time`` / ``projector_freq`` / ``projector_tfc`` (TF-C 원논문 따라 분리)
- ``pretrained/dp_neuronet/train.py``
  - augmentation 모듈 사용 폐지 (TF-C 자체가 두 view를 만든다)
  - tensorboard scalar 4개: ``L_T``, ``L_F``, ``L_TF``, ``Reconstruction``

## 11.5 Phase-2 (PhysioME-Hetero) 전이

Phase-1 ckpt에서 Phase-2가 들고 가는 것:
- ``frame_backbone`` (time only)
- ``autoencoder.patch_embed``, ``autoencoder.encoder``, ``autoencoder.cls_token``

**버려지는 것**:
- ``frame_backbone_freq`` (Phase-1 학습 보조용)
- ``projector_time/freq/tfc`` (SSL projection head)
- ``autoencoder.decoder_*`` (Phase-1 reconstruction head)

→ Phase-1에서 frequency consistency로 강해진 encoder가 Phase-2로 그대로 들어가고, frequency-specific 부품은 inference time에 부담을 주지 않는다.

## 11.6 향후 ablation (paper에 추가 가능)

| 변종 | 의도 |
|---|---|
| TF-C 전체 vs SimCLR baseline (원본) | TF-C 효과 입증 |
| $\mathcal{L}_{TF}$ 제외 | cross-domain alignment의 단독 기여 |
| Frequency view을 wavelet으로 교체 | spectral 표현 방식 ablation |
| Patient-aware sampling (같은 case 두 segment를 같은 batch에서 positive처리) | TF-C와 직교적인 false-neg 추가 완화 |

## 11.7 주의

- **기존 NeuroNet ckpt 재사용 불가** — `__init__`에 ``frame_backbone_freq``, projector 3개가 추가되어 state_dict key가 달라짐. Phase-1 다시 학습 필요.
- ``mask_ratio``는 두 도메인에 같은 값으로 적용. 도메인별 mask_ratio는 향후 ablation 후보.
- ``pretrained/dp_neuronet/augmentation.py``는 코드베이스에 **존치**하되 train loop에서는 호출하지 않음 (필요 시 ablation에서 재활성).
